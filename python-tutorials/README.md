# Python Tutorials

A practical, beginner-friendly path through Python. Each lesson is a standalone
Markdown file with short examples and exercises.

## Learning path

1. **01 - Basics**: values, variables, strings, numbers, and output
2. **02 - Control Flow**: conditionals, loops, and comprehensions
3. **03 - Functions**: reusable code, arguments, and scope
4. **04 - Collections**: lists, dictionaries, tuples, and sets
5. **05 - Files and Errors**: reading files and handling exceptions
6. **06 - Classes**: objects, methods, and dataclasses
7. **07 - Project**: build a small command-line todo app

## How to use these tutorials

You need Python 3.10 or newer. Check your installation with:

```bash
python3 --version
```

Read the lessons in order. Copy examples into a file such as `scratch.py`, then
run them:

```bash
python3 scratch.py
```

Try each exercise before looking at the solution. The project lesson combines
the earlier concepts into one useful program.
